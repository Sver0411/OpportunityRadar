# Open-source Foundation / Contributor Entry 来源

**适用缺口**：`portfolio`（缺公开产出）、`public_reputation`（缺公开影响力）、
`leadership`（缺 ownership 证据）。

很多开源机会**不在** `good first issue` 里，而在基金会程序、社区页、mentorship 程序、
工作组、SIG、contributor ladder、治理页与社区日历里。

## Source families

| family | 常见页面 | 典型 query intent |
|---|---|---|
| `foundation` | 基金会项目总览 | `<ecosystem> foundation contributor programme students` |
| `mentorship_program` | 导师制项目 / 申请轮次 | `<ecosystem> mentorship programme apply` |
| `working_group` | 工作组 / SIG / 技术委员会 | `<ecosystem> working group SIG join` |
| `contributor_guide` | contributor guide / ladder | `<ecosystem> contributor guide good first issue` |
| `community_event` | 社区日历 / CFP / 线下活动 | `<ecosystem> community event CFP open` |
| `maintainer_program` | 治理 / maintainer 路径 | `<ecosystem> maintainer pathway governance` |
| `project_repository` | 项目仓库 | `<project> contributors wanted` |
| `bounty_program` | 悬赏 / 付费贡献 | `<ecosystem> bounty programme` |

## ecosystem 由**用户领域**决定，不硬编码

CNCF / Linux Foundation / Apache / Eclipse / Python / Rust / Mozilla / OpenSSF 只是**种子示例**：
技术方向决定 ecosystem（嵌入式→Zephyr/FreeRTOS；安全→OpenSSF；数据→Apache 等）。
**不要**因为"用户做技术"就永远搜 CNCF。

## 缺口 → family

| 缺口 | 优先 family |
|---|---|
| 缺公开产出 | `contributor_guide` → `mentorship_program` → `foundation` |
| 缺公开影响力（升 Senior） | `community_event`（CFP/演讲）→ `working_group` → `maintainer_program` |
| 缺 ownership / 领导力证据 | `working_group` → `maintainer_program` → `foundation` |

**canonical source 判断**：基金会/项目官方域（`*.foundation`、`*.io` 项目站、GitHub org 主页）；
招聘板与聚合站只作 discovery。
