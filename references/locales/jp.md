# 日本（jp）

**加载条件**：目标地区包含日本时加载（`preferred_country` / 学校所在国 / 当前请求提到日本）。
不涉及日本的任务不要加载本文件。

搜索语言：`ja-JP` 为主，`en` 用于跨国公司、英文授课项目、海外远程机会。

## 2. 时间线按「卒業年度」而不是学年

企业筛选依据是**预计毕业年度**（`2028年3月卒業見込`），不是当前学年。

- 页面写"卒業年度"→ 记录到 `graduation_window`，并按**月份级**比较（3 月 / 9 月毕业是不同届）。
- 页面只写"学部生/修士"→ 归入 `education_level`，`student_year` 留 `null`。
- 不区分年级的 `インターンシップ` → `student_year: null`，不要自己推断。

## 3. 实习的分类（影响价值判断）

| 维度 | 取值 | 含义 |
|---|---|---|
| 报酬 | 有給 / 無給 | 明确写"無給"就是无薪，不要美化 |
| 时长 | 短期（1日〜2週）/ 長期（1ヶ月〜） | 长期通常更接近真实工作 |
| 选拔 | 選考直結型 / 非直結 | 直結型表现好可直通内定，价值更高 |
| 形式 | 対面 / オンライン / ハイブリッド | 线下需要签证与住宿安排 |

页面没写的项一律 `null`，不要推断（"日本企业一般都要求日语等级"是典型错误推断）。

## 4. 资格相关特有概念

- **在留資格 / ビザ**：以"資格外活動許可"在读期间打工有时长上限；实习是否算就业需看形态。
  页面写 `外国籍可` / `日本語能力N以上` 才可作为 Explicit 依据。
- **日本語能力**：JLPT 是常见门槛，但**页面没写就不代表要求 N2**（capability 支持解析 N2/N1，
  不代表可以假设）。同样注意 `日本語能力試験`、`JLPT`、`N1〜N5` 的写法。
- **国籍限制**：`日本国籍のみ` / `国内在住者` 是限制信号；`国籍不問` 是开放信号。

## 5. 求职周期（用于判断时效）

- 新卒採用：通常在毕业前一年半到一年开始（夏季〜秋季集中，春に追加选考）。
- インターンシップ：サマー（6〜9 月）、ウィンター（12〜2 月）为主，长期采用常年招募。
- `通年採用` / `随時募集` → 属于滚动招募，`deadline_type = rolling`。

## 6. 常见坑

- 把「卒業年度」当学年处理 → 资格判断会错一整届。
- 把 `応相談`（可协商）当成具体薪资。
- 把 `内定`（录用承诺）与 `内々定`（非正式内定）混为一谈。
- 用日本公司的所在地推断语言要求。
