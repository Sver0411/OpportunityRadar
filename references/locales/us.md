# 美国（us）

**加载条件**：目标地区包含美国时加载。不涉及美国的任务不要加载本文件。

搜索语言：`en-US` 为主。美国场景下英文就是当地语言，不需要"额外补英文"。

---

## 1. 搜索用词

| 意图 | 英文写法 |
|---|---|
| 实习 | `internship`、`summer internship`、`summer analyst`、`co-op`、`off-cycle internship` |
| 应届 | `new grad`、`entry level`、`graduate program`、`rotational program`、`campus recruiting` |
| 科研 | `undergraduate research`、`REU`（Research Experiences for Undergraduates）、`research assistant`、`lab assistant` |
| 竞赛 | `hackathon`、`case competition`、`datathon`、`CTF`、`student challenge` |
| 资助 | `scholarship`、`grant`、`travel grant`、`fellowship`、`stipend` |
| 活动 | `career fair`、`info session`、`open house`、`conference`、`meetup` |

`REU` 是美国特有的本科科研项目形态，值得单独搜；非美国场景不要套用这个词。

## 2. 工作许可（最关键的一类硬条件）

| 术语 | 含义 |
|---|---|
| `work authorization` | 是否具备合法工作资格 |
| `CPT` / `OPT` | 在读期间的实习许可 / 毕业后的实习许可（F-1 学生） |
| `sponsorship` | 公司是否提供签证赞助；`we do not sponsor` 是明确的排除信号 |
| `E-Verify` / `US citizen only` / `ITAR` | 部分岗位（尤其国防相关）限美国公民或绿卡 |

**判定规则**：页面写"must be legally authorized to work"或"no sponsorship"时，
若画像标注需要 sponsorship → `Probably Ineligible`；画像未提供签证状态 → `Unknown`
（"没写"不等于"不需要"）。

## 3. 时间线

- 暑期实习：大型公司常在前一年 8〜11 月就开始（秋招），滚动至次年春季。
- `new grad`：通常在前一年秋季开始，按毕业窗口（如 `Graduating between Dec 2027 and Jun 2028`）筛选。
- `co-op`：与学期交替，通常 6 个月，对在读年级有绑定。

## 4. 资格相关特有概念

- **GPA**：常见 `3.0/4.0` 及以上门槛；不同分值体系（4.0 / 100 / 5.0）**不做换算**，判 `Unknown`。
- **学分年级**：`freshman / sophomore / junior / senior` 对应 1〜4 年级。
- **学费与身份**：部分资助仅面向 `US citizens / permanent residents`，这是硬条件。

## 5. 常见坑

- 把 `OPT` 期间的实习与在读实习当作同一类资格要求。
- 用"公司在美国"推断工作地点在美国（可能是全球远程岗）。
- 把 `sponsorship not available` 当成"只是不方便"——它是明确的排除信号。
- 把 `volunteer` / `unpaid internship` 当成有薪实习记录。
