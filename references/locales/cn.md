# 中国（cn）

**加载条件**：目标地区包含中国大陆时加载。不涉及中国的任务不要加载本文件。

搜索语言：`zh-CN` 为主；英文只在跨国企业、国际项目、英文授课项目、海外远程机会时补充。
用户明确只看国内机会时，不必为"流程完整"额外搜英文。

## 2. 「应届生」身份由毕业年份决定

校招 / 提前批 / 补录几乎都按毕业年份筛选：

- 页面写"2027 届"、"2027 年应届毕业生"→ 记入 `graduation_window`。
- 画像缺少毕业年份时，资格判定应是 `Unknown`，**不能**默认用户符合或不符合。
- 区分「在校生」（可能含非应届）与「应届生」（严格按毕业年份），不要把两者当一回事。

## 3. 保研 / 推免相关（升学类）

- **推免资格**由学校层次 + 排名决定；画像没有排名信息时 → `Unknown`，不要推断。
- 时间线：夏令营（大三暑期，5〜7 月报名）→ 预推免（9 月）→ 推免系统开放（9 月底〜10 月）。
- 页面常写"仅限 985/211/双一流"或"专业排名前 X%"——这些都是**硬性条件**。

## 4. 常见语言与证书

- CET-4 / CET-6 是国内常见门槛（能力上可解析 `CET-4` / `CET-6` 与分数）。
  注意 CET-6 是**等级**、550 是**分数**，两者不是同一量纲，不要互相比较。
- 雅思/托福/考研英语在留学与部分岗位中是硬性条件。

## 5. 资格相关特有概念

- **户籍/国籍**：部分岗位或资助限"中国籍"；港澳台表述须按官方口径书写。
- **学籍限制**：`仅限本校学生`、`限合作院校` 之类是硬性条件，无法确认时 → `Unknown`。
- **应届生身份的有效期**：部分岗位允许"毕业两年内"，页面写了才按页面处理。

## 6. 常见坑

- 把去年（或更早）的招生简章当成本年机会 —— 中国升学类信息年份耦合极强。
- 把"预计时间线"当成本年确定的截止日。
- 页面写"详见附件/群通知"时，不要凭常识补全截止日期。
- 用中文页面存在就推断用户在中国（文档语言 ≠ 用户地区）。

## 7. 城市级定位（place hints）

中国的校招/实习/赛事信息高度城市化（"杭州""江浙沪""长三角"），`scripts/locales.py`
支持省/市级地名（省级 31 个 + 主要城市 + 江浙沪/长三角/珠三角/大湾区/京津冀 等区域短语）：

- 画像写 `constraints.preferred_city: ["杭州"]` 或请求里说"在杭州读书"→
  `place_hints: ["杭州"]`，query 应形如 `会计 实习 杭州`、`杭州 大学生 比赛`。
- 区域短语（江浙沪/长三角）按用户语义使用：说"不想去太远"时，把地名或"长三角"带进 query。
- 未收录的城市（如 贵阳）会原样保留在 `place_hints`，搜索时照常使用，不会报错。
