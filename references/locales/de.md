# 德国（de）

**加载条件**：目标地区包含德国时加载。

搜索语言：`de-DE` 为主，`en` 用于跨国公司、英文授课项目与研究所（德国科研机构大量使用英文招聘页）。
德语区其他国家（奥地利 `de-AT`、瑞士 `de-CH`）用词相近，可复用本文件，但**学制与国籍规则不同**，
不要把德国的规则直接套到瑞士。

---

## 1. 搜索用词

| 意图 | 德语写法 |
|---|---|
| 实习 | `Praktikum`、`Pflichtpraktikum`（必修实习）、`Freiwilliges Praktikum`、`Summer Internship` |
| 学生兼职 | `Werkstudent`、`Werkstudentin`、`studentische Hilfskraft`、`HiWi` |
| 论文 | `Abschlussarbeit`、`Bachelorarbeit`、`Masterarbeit`、`Thesis` |
| 应届 | `Berufseinstieg`、`Graduate Program`、`Trainee`、`Direkteinstieg` |
| 科研 | `HiWi`、`studentische Mitarbeit`、`Forschungspraktikum`、`Summer School` |
| 资助 | `Stipendium`、`Förderung`、`Reisestipendium`、`DAAD` |

`HiWi`（学生研究助理）与 `Werkstudent`（在读学生兼职）是德国特有形态，值得单独搜。

## 2. Pflichtpraktikum vs Freiwilliges

| 类型 | 特征 | 影响 |
|---|---|---|
| `Pflichtpraktikum` | 学校必修，有学分要求 | 通常有最低时长（如 8〜12 周）与实习协议要求 |
| `Freiwilliges Praktikum` | 自愿 | 可能涉及劳动法与社会保险规则差异 |

资格判断要看页面是否要求"在读证明"（`Immatrikulationsbescheinigung`）与必修证明。

## 3. 时间线

- 实习与论文岗位多为**滚动招募**（`laufende Bewerbung`）→ `deadline_type = rolling`。
- 大型企业（`Konzern`）的暑期实习通常提前 4〜8 个月开放。
- 冬季学期（`Wintersemester`）/ 夏季学期（`Sommersemester`）是常见的申请分界。

## 4. 资格相关特有概念

- **在读身份（`eingeschrieben`）**：`Werkstudent` 通常要求保持在读状态，毕业即失效。
- **语言要求**：德国岗位常直接写 `Deutschkenntnisse` 等级（A2/B1/B2/C1）或 `Englisch fließend`。
  CEFR 等级按单位比较；页面没写就不要假设（"德国公司"≠"要求德语"）。
- **工作许可**：非欧盟学生的工作许可有每周时长限制（常见 120 全天/240 半天每年），
  涉及长期兼职时作为 △ 提示。
- **国籍**：`EU-/EWR-Bürger` 限定是明确限制信号；`keine Sprachvoraussetzung`、`alle Nationalitäten`
  是开放信号。

## 5. 常见坑

- 把 `Pflichtpraktikum` 当成普通实习（必修实习的时长与证明要求完全不同）。
- 用"德国企业"推断德语要求。
- 忽略 `Immatrikulationsbescheinigung`（在读证明）这类必备材料。
- 把奥地利/瑞士的学制与签证规则当成德国规则。
