## OpportunityRadar 是什么？

OpportunityRadar 是一个帮助你寻找下一步机会的 Skill。它不只服务学生，也适合在职发展、晋升准备、转岗转行、出国发展、重返职场和探索新方向的人。

你只需要告诉它自己的情况和想法，例如：

> 我做了五年产品经理，想晋升或转向人工智能方向，现在可以做什么？

它会帮你寻找工作、实习、科研、比赛、奖学金、进修、开源项目、行业活动、社群和创业项目等机会，然后回到官方网站核实信息，最后告诉你：

- 哪些机会值得现在看；
- 哪些可能适合你；
- 哪些条件还不确定；
- 哪些已经结束或明显不符合；
- 下一步应该先做什么。

它追求的不是给你一大堆链接，而是帮你从很多选择中留下真正值得花时间的几条。

## 功能一览

| 功能 | 它会做什么 |
|---|---|
| **扩大搜索范围** | 覆盖 13 类机会，并根据国家和地区使用合适的搜索语言。 |
| **核实重要信息** | 尽量从官方网站确认开放状态、截止时间、要求和申请入口。 |
| **判断资格与准备情况** | 区分“符合条件”和“已经准备好”，列出仍需补充的信息或材料。 |
| **比较时间与成本** | 考虑每周投入、费用、准备难度和用户明确说出的限制。 |
| **找出真正的能力缺口** | 从目标机会的真实要求中总结反复出现的能力，而不是凭空判断。 |
| **寻找补缺口的机会** | 优先寻找能留下作品、公开贡献、研究或管理经历的真实项目。 |
| **安排机会组合** | 在时间预算内区分现在要做、低成本尝试和长期选择。 |
| **减少重复搜索** | 可在本地记录看过、收藏、忽略或已经申请的机会，并识别重要变化。 |

## 你会看到什么结果？

结果会分成三组，不把不同状态的机会混在一起：

| 结果 | 代表什么 |
|---|---|
| **现在值得看** | 官方信息和当前状态已经核实，没有发现明确冲突。 |
| **值得继续确认** | 看起来有价值，但开放状态或申请条件还没有完全查清。 |
| **已经结束或不符合** | 已过期、已关闭，或者存在明确的资格冲突。 |

每条重要推荐都会尽量回答这些问题：

```text
为什么推荐给我？
我是否符合条件？
现在还能不能参加？
大概要投入多少时间？
参加后能留下什么？
我接下来应该先做什么？
```

如果你告诉它“每周最多投入 6 小时”，它也会检查推荐的总投入是否超过预算，而不是给出一份根本做不完的计划。

如果你已经有明确目标，例如“转行做数据分析”或“准备晋升管理岗”，它还会查看相关机会反复要求什么，并继续寻找能补上这些经历的真实项目。

## 适合哪些人？

| 你现在的情况 | 可以寻找什么 |
|---|---|
| **学生或应届生** | 实习、科研、比赛、交换、奖学金、开源和作品项目。 |
| **正在工作** | 新岗位、行业项目、进修、专业社群、演讲和公开贡献机会。 |
| **准备晋升** | 能积累领导力、行业影响力、管理经验或公开成果的机会。 |
| **准备转岗或转行** | 目标岗位、常见要求，以及能补经验和作品的过渡项目。 |
| **准备出国发展** | 海外工作、升学、研究、资助、交流和跨国项目。 |
| **管理者或资深从业者** | 行业组织、导师计划、评审、演讲、合作研究和创业项目。 |
| **重返职场或自由职业** | 灵活、远程、短期项目，以及能够重新建立履历的机会。 |
| **方向还不明确** | 投入较小、差异较大的尝试，用实际体验帮助判断方向。 |

OpportunityRadar 不限制专业。设计、商科、工程、生物、环境、人文和技术方向都可以使用。

## 可以这样问

```text
我是视觉设计专业的学生，最近有什么能留下真实作品的项目？

我工作五年了，想升管理岗，有哪些机会能补领导力和行业影响力？

我在做嵌入式开发，想转行到边缘人工智能，现在可以参加什么？

我准备去德国工作或读研，有哪些项目、资助和交流机会值得看？

我离开职场两年了，想重新开始，有没有时间灵活的项目？

我暂时不想换工作，每周只有 5 小时，有什么能为晋升铺路？

我还不知道以后想做什么，帮我找几个差别大一点的方向。
```

不需要先填写完整资料。一句话就可以开始；只有在缺少的信息会影响判断时，它才需要继续追问。

## 安装

把仓库放进支持 Agent Skills 的工具的 skills 目录，文件夹名称应为 `opportunity-radar`。

以 Codex 为例：

```bash
mkdir -p ~/.codex/skills
git clone https://github.com/Sver0411/OpportunityRadar.git \
  ~/.codex/skills/opportunity-radar
```

安装后，直接用自然语言提问即可。

寻找和核实真实机会需要工具能够搜索网页并打开页面。项目中的辅助脚本支持 Python 3.8+，只使用标准库；没有 Python 时仍然可以按照 [`SKILL.md`](SKILL.md) 中的流程工作，但日期、去重和评分需要人工判断。

## 几条基本原则

- **重要信息尽量看官方网站。** 第三方页面可以提供线索，但不能代替官方确认。
- **不知道就是不知道。** 用户没说过的情况不会被当成事实，网页没写清楚的条件也不会被猜出来。
- **明确冲突优先。** 如果页面写着“仅限博士生”，就不会因为方向很匹配而推荐给本科生。
- **宁可少，也不凑数。** 没有足够好的结果时，就少推荐几条。
- **不会替你直接报名。** 提交申请、发送邮件、注册账号和上传个人资料不在本 Skill 的执行范围内。

<br>

## 使用边界

机会信息会变化。真正行动前，请再次打开官方网站确认最新要求和时间。

OpportunityRadar 不能保证搜遍所有网站，也不能保证申请结果。它能做的是帮你找得更广、查得更清楚，并减少把时间浪费在过期或不合适机会上的可能。

可选的用户资料和查看记录保存在本地 `.opportunity-radar/`，辅助脚本不会主动上传这些文件。
