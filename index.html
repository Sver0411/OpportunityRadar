OpportunityRadar

一个帮助你寻找下一步机会的 Skill。它会扩大搜索范围、回到官方页面核实信息、判断是否适合，并告诉你现在应该先看什么。

没有找到相关内容。可以换一个更短的关键词。

它是什么

#

OpportunityRadar 是一个个人机会发现 Skill。你告诉它自己的阶段、方向和限制，它会寻找相关机会，并尽量回到官方页面确认报名时间、申请条件和入口。

它追求的不是给你一大堆链接，而是从很多选择中留下真正值得花时间的几条。

一句话理解：你问“我现在可以做什么”，它帮你回答“哪些值得看、为什么适合、现在能不能参加、下一步做什么”。

适合哪些人

#

OpportunityRadar 不限制专业，也不只服务学生。只要你正在寻找下一步，就可以使用。

你现在的情况可以寻找什么
学生或应届生实习、科研、比赛、交换、奖学金、开源和作品项目
正在工作新岗位、行业项目、进修、专业社群、演讲和公开贡献
准备晋升能积累领导力、行业影响力、管理经验或公开成果的机会
准备转岗或转行目标岗位，以及能补经验、技能和作品的过渡项目
准备出国发展海外工作、升学、研究、资助、交流和跨国项目
管理者或资深从业者行业组织、导师计划、评审、演讲、合作研究和创业项目
重返职场或自由职业远程、灵活、短期项目，以及能够重新建立履历的机会
方向还不明确投入较小、差异明显的尝试，用真实体验帮助判断方向

可以找什么

#

项目覆盖 13 类机会。你可以只指定一类，也可以让它根据目标跨类别寻找。

工作实习科研竞赛开源奖学金升学交流行业活动专业社群志愿服务创业机会作品项目

例如，想转行时不一定只看招聘岗位。开源项目、行业挑战和短期合作，也可能是更适合当前阶段的入口。

扩大搜索范围

#

普通搜索只能找到你已经知道名称的东西。OpportunityRadar 会根据你的专业、兴趣、目标和所在地区，继续展开可能相关的方向。

跨类别

不把所有问题都变成工作或实习，会同时考虑项目、研究、开源、活动等机会。

跨语言

根据目标国家和地区使用合适的搜索语言，减少只看到中文或英文结果的遗漏。

找相邻方向

从你已经说出的目标向外扩展，但不会无限联想或偏离你的实际背景。

尊重明确范围

当你只想找某一类、某个地区或远程机会时，不会为了数量加入无关结果。

核实真实信息

#

搜索结果、招聘平台和论坛可以提供线索，但不能直接证明一个机会现在仍然开放。重要信息会尽量回到主办方、学校、公司或项目的官方页面确认。

  • 现在是否开放，截止时间是什么时候；
  • 谁可以申请，有哪些硬性要求；
  • 正式申请入口在哪里；
  • 页面信息是哪一轮、哪一年或哪个批次。
没有证据就不会写成事实。 如果官方网站也没有说清楚，结果中会直接标出“需要确认”。

判断是否适合

#

“方向很匹配”和“能够申请”是两件事。项目会对照学历、年级、毕业时间、语言、地点、身份和技能等条件，先排除明确冲突。

判断代表什么
符合现有信息没有发现资格冲突，关键条件已经确认
大概率符合主要条件匹配，但仍有少量信息需要核实
无法判断用户资料或官方说明不足，需要继续确认
大概率不符合存在明显风险，但还不能完全确定
不符合发现明确的硬性条件冲突

它不会把你没说过的成绩、技能或语言水平当成已知事实。

安排优先顺序

#

适合你的机会不一定都值得现在投入。排序时会分别考虑：

  • 匹配：它与你的背景和目标是否相符；
  • 优先：是否临近截止，当前是否需要马上行动；
  • 价值：考虑投入、成本、结果和未来作用后，现在是否值得做。

如果你给出每周可用时间、费用上限或地点限制，推荐组合会一起遵守这些条件。

发现并补足缺口

#

当你的目标明确，例如“转行做数据分析”或“准备晋升管理岗”，项目会先查看真实目标机会反复要求什么，再寻找能补上这些经历的真实项目。

目标机会 → 反复出现的要求 → 当前缺少的证据 → 可以参与的过渡机会 → 新的作品或经历

它优先寻找能留下公开贡献、作品、研究或管理经历的机会，而不是简单列出一批课程。

减少重复搜索

#

启用本地记录后，可以保存已经看过、收藏、忽略或申请的机会。下一次搜索时，项目能够减少重复展示，并检查截止时间、开放状态等重要信息是否变化。

这些记录保存在本地，不会由辅助脚本主动上传。

它怎样工作

#
  1. 理解你的情况确认当前阶段、目标、地区和明确限制。
  2. 建立搜索范围从多个机会类别、地区和语言展开，而不是只重复原问题。
  3. 寻找候选先广泛发现，再找到每个机会的正式来源。
  4. 核实与判断检查时效、申请资格、投入、成本和准备程度。
  5. 去重与排序合并重复结果，排除已过期或明确不符合的机会。
  6. 给出下一步分清现在值得看、需要继续确认和已经排除的内容。

怎样阅读结果

#
结果区域怎样理解
现在值得看官方来源和近期状态已经核实，没有发现明确的资格冲突
值得继续确认看起来有价值，但开放状态、资格或来源还没有完全查清
已经结束或不符合已经过期、关闭，或者存在明确冲突，并附上排除原因

每条重要推荐会尽量说明：它是什么、为什么适合、能否申请、现在是否开放、需要投入什么，以及接下来先做什么。

可以怎样提问

#

不需要先填写完整资料。一句话就能开始，真正影响判断的信息缺失时，它才会继续追问。

我是视觉设计专业的学生，最近有什么能留下真实作品的项目？
我工作五年了，想升管理岗，有哪些机会能补领导力和行业影响力？
我在做嵌入式开发，想转行到边缘人工智能，现在可以参加什么？
我准备去德国工作或读研，有哪些项目、资助和交流机会值得看？
我离开职场两年了，想重新开始，有没有时间灵活的项目？
我还不知道以后想做什么，帮我找几个差别大一点的方向。

安装与使用

#

把仓库放进支持 Agent Skills 的工具的 Skills 目录。以 Codex 为例：

终端
mkdir -p ~/.codex/skills
git clone https://github.com/Sver0411/OpportunityRadar.git \
  ~/.codex/skills/opportunity-radar

最终目录名应为 opportunity-radar。安装后，直接用自然语言提问即可。

  • 发现和核实真实机会需要工具能够联网搜索并打开网页；
  • 辅助脚本支持 Python 3.8+，只使用标准库；
  • 没有 Python 时仍可按流程工作，但日期、去重和评分改为人工判断。

基本原则

#

重要信息看官方

第三方页面可以提供线索，但不能代替正式来源确认。

不知道就是不知道

用户没说过、网页没写清楚的内容，不会被猜成事实。

明确冲突优先

硬性条件不符合时，不会因为方向相似而强行推荐。

宁可少，也不凑数

没有足够好的结果时，就少推荐几条。

使用边界

#

OpportunityRadar 不能保证搜遍所有网站，也不能保证申请结果。它能做的是找得更广、查得更清楚，并减少把时间浪费在过期或不适合机会上的可能。

它不会替你提交申请、发送邮件、注册账号或上传个人资料。真正行动前，也应该再次打开官方网站确认最新要求。

项目结构

#
位置用途
SKILL.md说明什么时候启用，以及完整的寻找和判断流程
references/搜索、来源、资格、地区和结果展示的详细规则
scripts/日期处理、去重、评分、证据检查和时间分配工具
schemas/用户资料和机会记录的数据格式
examples/用于演示的虚构数据，不能当作真实机会
tests/单元测试、回归测试和一致性检查

开发与验证

#

项目辅助脚本只使用 Python 标准库。修改后可以运行完整测试：

终端
python3 -m unittest discover -s tests -t tests

设计取舍和维护说明见 DEVELOPMENT.md。

本地数据

#

可选的用户资料和查看记录保存在本地 .opportunity-radar/ 目录。辅助脚本不会主动上传这些文件。

你始终可以只使用搜索和判断流程，不保存本地画像或历史记录。
